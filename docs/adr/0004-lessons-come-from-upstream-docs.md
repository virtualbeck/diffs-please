# Lessons come from the upstream skill docs

Every lesson, answer and line of feedback must be traceable to the README or a SKILL.md in mattpocock/skills, read at the time of writing. The first design was drafted from memory and named skills that upstream had since renamed, so the game is now written from a fresh checkout instead. The game does not invent tenets or add advice of its own.

## Consequences

- Upstream changes can make a case wrong. Re-read the affected SKILL.md before editing a case, and check the skill still exists under that name.
- Skills that upstream marks as in progress stay out of the game.

_Recorded on 2026-11-16, after the decision was made during the build._
