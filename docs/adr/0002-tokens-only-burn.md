# Tokens only burn

The player gets a daily token budget and can only spend it. An earlier build paid tokens for each finished case, borrowed from the wage loop of the game that inspired this one. It was dropped because nobody earns tokens by using an agent: you spend them, and a mistake spends more for nothing. The score is avoidable burn, not a balance.

## Considered options

- Pay per case, with fines for mistakes. Familiar as a game loop, but it teaches the wrong model of real usage.

_Recorded on 2026-11-16, after the decision was made during the build._
